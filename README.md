# Klipper in docker, for my Ender 3
## 3D printer
- Ender 3 (v1)
- BIGTRETECH SKR Mini E3 V2.0, 32-bit motherboard
- Micro Swiss direct drive (all metal hotend)
- Dual Z in one driver with parallel cable
- BLtouch
- stock LCD display and PSU

## RPi
- RPi 5, 16GB RAM
- raid5 SSD drives on Radxa Hat
- general homeserver with other services in docker containers

## Features
- connected via USB
- runs in a docker container
- hidden behind nginx login form

## Tech-Stack
- klipper
- moonraker
- mainsail
- nginx
